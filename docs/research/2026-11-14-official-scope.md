## 复现

```sh
python tools/documents/verify.py --input data/official-docs/2026-11-14
python -m harness.source_inventory \
  --catalog data/official-docs/2026-11-14/catalog.json --repo . \
  > data/reports/2026-11-14-sdk-document-links.json
```

`--summary-only`输出分类统计与输入hash。关联工具不读取raw_file、不联网、不导入SDK；原始文件完整性由第一步独立验证。此摘要是有输入hash的批次记录，新增契约或更换快照后应重新生成，不能套用旧数字。
