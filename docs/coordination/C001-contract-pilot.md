# C001：接口契约整理试点

目标：验证“Claude Code 执行、Codex 验收”的协作链路。当前任务只整理文档契约，不实现 SDK，不调用真实接口。

输入为 `C001-input.json`，源文档取自已归档官方数据：国内81、675；海外476的1.5节、2867。输入中的公共示例 token 会被替换为占位符；原文哈希与路径保留供主导方核对。

输出为4项 JSON 契约，包含 method、path、编码、token位置、参数表、响应成功规则、时间/权限约束、不确定项及直接证据。仅依据给定输入，不把国内规则移植到海外。

Claude Code 经 Magpie 使用 `devin/swe-2`，以无工具模式输出候选 JSON；由 Codex 保存、验证。它不修改项目文件，不读取凭据或其他会话，不访问网络或启动子代理。

验收重点：

1. 国内 token 请求为 POST/form；expireTime 单位为毫秒，7天有效期只适用于该国内来源。
2. 国内与海外设备状态请求使用 `channel`，不能改写为 `channelNo`。
3. 海外录像查询为 GET，token与设备信息按文档放Header，时间条件在Query。
4. 顶层 `code` 与 `meta.code` 分开描述，成功值类型与文档一致。
5. 每项关键规则能够定位到输入中的原文证据；未知信息明确保留。

执行与验收记录写入同目录的 `C001-result.json`、`C001-run.json` 和 `C001-review.json`。结果只有在审查后才能标记为 accepted。
