# EZVIZ Unified 实施路线

**目标：** 持续完成统一国内与海外官方能力的 Python SDK，并建立可验证的维护流程；App 数据扩展与受控自我改进按独立阶段推进。任何单个批次完成都不代表整个目标完成。

**分工：** Codex 负责架构、关键验收与集成；Claude Code 经 Magpie 使用 `devin/swe-2`、effort=max，执行边界明确的整理和实现任务。后台只读任务生成候选结果，Codex 审核后写入；不关闭后台隔离规则。

## 验收规则

接口数、文件数、跳过测试和模型完成声明都不能代替正确性证据。离线、真实只读、真实写操作及维护 eval 分开报告。不会为满足覆盖目标猜测官方缺项或自动操作真实设备的破坏性接口。

源码与运行依赖留在核心包；原始文档数据、模型调用和维护调度不进入 SDK wheel。每阶段有具体交付与验证记录，未完成阶段继续保留在路线中。
