# 云台、预置点与巡航迁移

当前来源：国内679–684、686、4477、4993、5063、5065、5066，海外479。公开入口为client.ptz及client.ptz.cruise，同步/异步对等，所有返回保持ApiResponse。只做离线请求验证，不操作真实设备。

## Ptz / AsyncPtz

- start(device_serial, direction, *, channel=1, speed=1)：POST /api/lapp/device/ptz/start，form含deviceSerial/channelNo/direction/speed。方向国内0–11或16，海外0–11；speed为0/1/2。国内海康设备不接受speed=0属于型号约束，由调用者按设备能力判断。开始后必须显式stop才能进行其他控制，close只释放HTTP连接。
- stop(device_serial, *, channel=1, direction=None)：POST /api/lapp/device/ptz/stop。国内direction可省略；海外表格要求必填，虽然示例漏掉该字段，SDK按参数表要求显式传入并保留矛盾记录。
- mirror(device_serial, command, *, channel=1)：POST /api/lapp/device/ptz/mirror，form command为0/1/2。
- add_preset(device_serial, *, channel=1)、move_preset(device_serial, index, *, channel=1)、clear_preset(...)：对应/lapp/device/preset/add、move、clear，form字段channelNo及可选index。index只校验整数，不能把C6的1–12上限套用所有型号。
- 上述六项均支持国内/海外，code为字符串200，token在form；均为写操作，禁止重放。国内序列号英文字母须大写；海外不套用此规则；整数参数拒绝bool，无文档依据时不擅自限定channel/index范围。
- presets(device_serial, *, channel=1)：仅国内GET /api/service/device/preset/list，token在header，deviceSerial/localIndex在query，localIndex转换字符串；meta.code整数200，只读。
- calibrate(device_serial, *, channel=1)：仅国内POST /api/v3/device/ptz/manual/adjust，token/deviceSerial/localIndex在header，无body，code字符串200，写操作。
- reset(device_serial)：仅国内POST /api/v3/device/ctrl/ptz/reset，token/deviceSerial在header，无channel/body，meta.code整数200，写操作。
- presets/calibrate的channel接受非空字符串或整数，reset不接受channel；这三页未声明序列号大写要求，不能添加。未经验证的海外对应入口应在请求前拒绝。

## Cruise / AsyncCruise

仅国内：get_enabled(device_serial, *, channel=1) GET /api/v3/device/ptz/cruise/auto/switch；token/deviceSerial/localIndex在header。code字段表写string、示例为int，策略接受200与"200"并记录类型矛盾。get_schedule(device_serial) GET /api/v3/device/ptz/cruise/timePlan，只需token/deviceSerial Header，meta.code整数200。

set_schedule(device_serial, *, enabled: bool, periods: Sequence[CruisePeriod]) POST同timePlan路径，Header同get_schedule，form enable=0/1、timerDefenceQos为JSON数组字符串。CruisePeriod(start: str,end: str,weekdays: tuple[int,...])为frozen dataclass；HH:mm严格格式，end>start，weekdays为0–6非空唯一整数，0=周一，拒绝bool。序列转tuple防止输入别名；periods空数组未被文档禁止，允许原样传递。只设置并覆盖时间计划，不自动配置预置点或开启巡航；请求不重放。

5064的巡航开关设置存在body参数表与query示例冲突，无法确认编码，本轮不伪造set_enabled支持，记录为未核实待迁移。5065返回timingPlanBasicInfos表写string、示例为数组；直接保留raw数据，不自动转换。这些待核实项仍属于完整目标范围。
